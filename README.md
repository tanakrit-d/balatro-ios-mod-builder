# Balatro Modded

Creates two separate modded versions of Balatro for iOS, each packaged as its own IPA.

## Balatro (MP)

Includes [Balatro Multiplayer](https://github.com/Balatro-Multiplayer/BalatroMultiplayer), which adds online competitive play. Create or join a lobby to play against other players.

## Balatro (PK)

Includes [Pokermon](https://github.com/InertSteak/Pokermon), which adds Pokémon-themed Jokers and new content to Balatro. Build your run around a team of Pokémon Jokers.
